# CodeAlpha_EmailExtractor

Small automation script for the CodeAlpha Python internship (Task 3).

## What it does
Reads a `.txt` file, finds email addresses with a regex, and writes the unique list to another file.

## How to run
```bash
python extract_emails.py
```
Press Enter to use `sample_input.txt` and `emails.txt`.

## Concepts used
`re`, file handling.
